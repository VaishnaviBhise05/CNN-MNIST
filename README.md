# CNN MNIST Digit Classification

A Convolutional Neural Network (CNN) built using TensorFlow/Keras to classify handwritten digits from the MNIST dataset.

## Features

- TensorFlow/Keras implementation
- Trained on MNIST dataset
- Image preprocessing
- Model training and evaluation
- Predict handwritten digits

## Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset

- MNIST Handwritten Digits

## Results

The model achieves high accuracy on the MNIST test dataset.

## Run

```bash
pip install tensorflow matplotlib numpy jupyter
```

Open:

```
CNN_Mnist.ipynb
```
